# 👥 SplitMates

SplitMates is a simple and powerful group expense tracker application designed to take the stress out of sharing costs with friends. By creating an account, you can easily set up multiple groups, add shared expenses, track activities, and see exactly who owes whom without doing any mental math.

🔗 **Live Demo:** [Deploy Link](https://split-mates-five.vercel.app/)

---

## ⚡ Three Steps to Zero Drama

1. **Add Expenses**  
   Enter the total and select which participants to include in the split.
2. **Split Fairly**  
   Choose equal or custom manual splits — SplitMates handles the math.
3. **Settle Up**  
   See exactly who owes whom and settle it up.

---

## ✨ Features (Everything your group needs)

* **👥 Group Management**  
  Create multiple groups for any occasion — trips, rent, dining, and events.
* **🧮 Smart Math**  
  Automatic calculations with equal or exact-amount splits.
* **📊 Track History & Activities**  
  Keep a running record of all expenses and settle up anytime with complete transparency.
* **🔐 User Authentication**  
  Create a secure account to save your dashboard, groups, and activity logs.
